# World Indicators Analysis Dashboard
This project presents an interactive Tableau dashboard created using the World Indicators dataset.

## Project Overview
The dashboard analyzes various global indicators, including GDP, population, life expectancy, internet usage, and CO2 emissions.

## Visualizations
- GDP by Region
- Population Total by Region
- GDP Trend Over Time
- Top 10 Countries by GDP
- Interactive filters for Region, Country, and Year

## Tools Used
- Tableau
- CSV Dataset
- GitHub

## Files
- `World-Indicators-Analysis.twbx` – Tableau workbook
- `World-Indicators.csv` – Dataset
